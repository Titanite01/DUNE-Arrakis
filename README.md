# DUNE-Arrakis
Friendly low-fi Arrakis remake

How to collab:

1. Get invited to the club
2. Get access to the exclusive texture bank and gamer templates
3. Open github for desktop, select 'clone repository' and place the files into a prepped folder.
4. Edit the files as you wish in workstation mode.
5. Save your files and 'publish repository' back to the main branch
6. collab!
